
# BMI Calculator

## Description
A simple Body Mass Index (BMI) calculator designed using HTML, CSS, and JavaScript. This project allows users to input their height and weight to calculate their BMI and determine their weight category.

## Features
- User-friendly interface
- Real-time BMI calculation
- Displays weight category based on BMI value

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Dahiya4145/BMI-calculator.git
   ```
2. Navigate to the project directory:
   ```bash
   cd BMI-calculator
   ```

## Usage
1. Open `index.html` in your preferred web browser to use the BMI calculator.
2. Enter your height and weight to get your BMI value and weight category.
3. Alternatively, use the live preview link: (https://dahiya4145.github.io/BMI-calculator/)

## BMI Calculation Formula
The BMI is calculated using the following formula:
$$ BMI = \frac{weight \ (kg)}{height \ (m)^2} $$

For example, if a person weighs 70 kg and is 1.75 meters tall, their BMI would be calculated as follows:
$$ BMI = \frac{70}{1.75^2} = 22.86 $$
